# TR GARAGE 031

Vitrine automotiva mobile-first, sem Supabase e sem banco de dados. Os produtos e avaliações são armazenados temporariamente no `localStorage` do navegador, deixando a estrutura pronta para uma futura integração permanente.

## Rodar

```bash
npm install
npm run dev
```

## Painel administrativo

Acesse pelo link discreto **Admin** no rodapé ou por `/#admin`.

Senha temporária: `trgarage031`

> Como não há backend nesta versão, a autenticação e os dados são locais ao navegador. Para segurança real e acesso privado em produção será necessário conectar um backend posteriormente.
